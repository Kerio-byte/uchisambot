# UchiSamBot — школьный разборщик задач

Бот в Telegram: разбирает школьную задачу по шагам и объясняет простым языком, почему каждый шаг работает, а в конце даёт готовый ответ — чтобы можно было сверить со своим решением.

Десять языков: русский, английский, испанский, португальский, хинди, индонезийский, турецкий, вьетнамский, украинский, финский.

- Бот: https://t.me/UchiSamBot
- Сайт: https://kerio-byte.github.io/uchisambot/
- Связь: через контактную форму на сайте

Первые 30 разборов бесплатно, дальше — по звёздам Telegram.

## Что в этом репозитории

Только готовый сайт — то, что видит посетитель. Инструменты сборки, служебные проверки и рабочие журналы в репозиторий не входят.

## Конфиденциальность

Мы не собираем личные данные. Храним только текст задачи и ник в Telegram, чтобы показать разбор и историю. Подробно — в политике конфиденциальности на сайте.
